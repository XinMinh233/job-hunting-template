# 管理员与用户手册

## 管理员

超级管理员从 `/admin` 进入管理面板。
管理员自身也在首次引导时获得独立 Linux 工作空间，因此可以返回普通工作台使用求职功能；不要把管理员密码交给其他用户。

### 开通账号

点击“开通用户”，设置用户名和每日额度。系统会先建立业务账号，再由 Runner 创建锁定的 Linux 用户、`0700` HOME/workspace、复制模板并初始化独立 Git 仓库。

创建成功后临时密码只显示一次。请用安全渠道交给对应用户，不要截在公共群聊里。系统不会保存明文密码。

### 停用与启用

停用会：

- 禁止新的 Web 请求和 DeepSeek 代理请求；
- 标记 Runner registry 为不可运行；
- 停止该用户当前 transient unit。

目录和历史不会删除，可由管理员重新启用。停用不是数据删除功能。

### 重置密码和额度

重置密码会生成一次性临时密码，默认要求用户下次登录修改。额度调整对下一次任务检查生效；运行中的任务允许完成。任务额度按创建任务计数，Token 以 DeepSeek 响应中的 usage 为准；自然日边界由 `JOBHUNT_QUOTA_TIMEZONE` 配置，默认 `Asia/Shanghai`。

### 停止任务

管理员可停止任意排队或运行任务。停止运行任务时，Runner 对整个 transient systemd unit 执行 stop，包含 Claude 生成的子进程。

## 普通用户

### 首次登录

使用管理员提供的用户名与临时密码。首次进入会强制设置至少 12 字符的新密码，然后进入工作台。

### 会话

每个 Web 会话保存一个明确的 Claude session ID。继续在同一会话发送消息会使用 `--resume`；新建会话会建立新的 Claude session。归档只影响 Web 列表，不删除 Git 文件或 Claude HOME。

浏览器关闭或网络断开不会取消任务。重新打开后可以继续看到已持久化事件。需要停止时点击右上角“停止任务”。

### 文件

可上传 TXT、Markdown、CSV、JSON、YAML、PDF 和 DOCX，单文件不超过 10 MB，个人上传总量默认不超过 100 MB。PDF/DOCX 会同时生成只读文本副本，便于 Claude 读取。界面返回的路径可以直接粘贴到对话里。

上传会作为一个独立 Git 提交保存，因此任务运行或排队期间不能同时上传；请等待任务结束。上传原文件和提取文本都由 root 设为只读，Claude 不会覆盖原始资料。

“文件与产物”只显示 `master.md`、`base/`、`tailored/`、`dist/`、`data/`、`uploads/`。Markdown 使用站内安全渲染页面预览（单文件上限 2 MB），HTML/PDF 使用浏览器预览；其他类型只提供下载。

### 常用命令

- `/onboard`：建立个人档案与求职规则。
- `/match <JD>`：职位匹配评估与记录。
- `/tailor <目标>`：定制材料。
- `/pdf`：生成 PDF 产物。
- `/scout <范围>`：较长的职位调查任务，最长 30 分钟。

权限请求不会自动批准。如果 Claude 尝试安装包、使用 sudo/Docker 或运行未允许命令，任务会返回错误；请联系管理员判断是否应把一个固定、安全的动作加入模板，而不是临时放开全部权限。
