# base/ — one full-length resume per track

Base resumes are derived from `master.md` (never edited with new
facts directly) — one per track you pursue, e.g.
`base_resume_data_analyst.md`, plus a language variant if you apply
in two languages. `/onboard` creates your first one; `/tailor` picks
the right one per posting and derives a dated, posting-specific copy
into `tailored/`.
